# 典型方法

- 要判断一个元素是否出现在集合里，必须想到哈希

- 注意题目有序无序、能否重复，空间是否过大等等，选择合适的数据结构

- 快慢指针判断循环，不光是链表中有环，还能是结果的循环出现

- 分组哈希，空间换时间

- 几数之和，肯定优先想到哈希表或分组哈希（如果三数之和要求放宽点导致哈希方法去重不难的话，用哈希就要考虑1+2还是2+1分组了）。行不通再换别的方法，不要害怕沉没成本，做题本来就是验证思路对错，走弯路是很正常的。其他方法，比如数组里面的，先定一个数，然后双指针来降复杂度(比如$n^2$->$n$)。

  ==ps:双指针能降复杂度也是很逆天的特性，要记住，但可能依赖有序，从而引入排序操作==
