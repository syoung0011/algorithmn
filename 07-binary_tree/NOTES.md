# 典型方法

- 树的问题，基本上逃不掉遍历，代码都会有前中后序，或是层次的影子，且递归是这些遍历的较为简单的实现，往这里靠，思路会好像很多
-  长指针判断，cur->left->left也是可行的，只要逻辑理清，边界（如上层指针不空再下层，可以用&&短路配合）处理得当，就没问题，不用执着于奇技淫巧
- 算法题可以多用点全局变量
