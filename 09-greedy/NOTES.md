# 典型方法

- 贪心，从局部最优推整体最优
- 不要再if(A > B) A = B了，直接用max，更何况有的时候A 换为 C + D，这样还能省一个显示加法

# 题目回顾

## leetcode_122_best_time_to_buy_and_sell_stock_ii

典型贪心，无法下手，那就考虑回归题目要求，摆弄条件，比如这里差值就是最为关键的，如果能列出差值数组，那更是到了临门一脚，而差值的意义不用深究，比如哪天买入，哪天卖出，因为只要差值为正，说明那天买入，另一天卖出是赚的，如果连续正，说明可以继续持仓，如果中间卖出，则需要再买入反而亏了，其实想想也能理解。但是关键就是差值+数组

## leetcode_1005_maximize_sum_of_array_after_k_negations

重点是贪在哪里，一次是要先将所有负数取反（有顺序），一次是对最小的正数取反，所以按绝对值排序只需一次。

复杂度分析不要忘记排序sort函数，引入的复杂度。除去排序肯定是n，但是排序引入nlogn。

贪心，从局部最优推全局最优，以上两次贪心，都要能否解释！！！
